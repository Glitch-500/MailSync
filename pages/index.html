API Reference

      
Send emails simply by issuing a standard HTTP request with a JSON body.


      

        

          POST
          /mail
          (Also available at /api/mail)
        


        

          
Request Body (application/json)

          

            
              

                Field
                Type
                Required
                Description
              

            
            
              

                email or to
                String
                Yes
                Recipient email address (e.g. user@example.com).
              

              

                message
                String
                Yes*
                Plaintext message body (automatically wrapped in a responsive HTML layout).
              

              

                subject
                String
                No
                Email subject line (defaults to "New Notification from MailSync").
              

              

                name
                String
                No
                Recipient name for personalized greeting in the email body.
              

              

                html
                String
                No
                Custom HTML body if you wish to bypass automatic templating.
              

            
          


          
Security Headers

          

            If ACCESS_KEY is defined in your environment, pass it via header:
            x-access-key: YOUR_KEY or
            Authorization: Bearer YOUR_KEY.
