API Schema Reference

        
Send emails simply by issuing a standard HTTP POST request with a JSON body.

      


      

        

          

            
              

                Field
                Type
                Required
                Description
              

            
            
              

                email or to
                String
                Yes
                Target recipient email address (e.g. user@example.com).
              

              

                message
                String
                Yes*
                Plaintext message body (automatically wrapped in a responsive HTML layout).
              

              

                subject
                String
                No
                Email subject line (defaults to "New Notification from MailSync").
              

              

                name
                String
                No
                Recipient name for personalized greeting in the email body.
              

              

                fromName
                String
                No
                Custom sender/from name (e.g. "Acme Support"). Overrides the FROM_NAME
                  environment variable.
              

              

                from
                String
                No
                Full custom sender address (e.g. "Acme" <support@domain.com>).
              

              

                html
                String
                No*
                Custom HTML body if you wish to bypass automatic templating.
