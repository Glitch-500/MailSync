API Schema Reference

        
Send emails simply by issuing a standard HTTP POST request with a JSON body.

      


      

        

          

            
              

                Field
                Type
                Required
                Description
                Quick Action
              

            
            
              

                email or to
                String
                Yes
                Target recipient email address (e.g. user@example.com).
                
              

              

                message
                String
                Yes*
                Plaintext message body (automatically wrapped in a responsive branded HTML layout).
                
              

              

                html
                String
                Optional*
                Custom HTML body if you wish to bypass automatic templating with your own markup.
                
              

              

                subject
                String
                No
                Email subject line (defaults to "New Notification from MailSync").
                
              

              

                name
                String
                No
                Recipient name for personalized greeting in the email body (e.g. "Hello Alex,").
                
              

              

                fromName
                String
                No
                Custom sender name (e.g. "Acme Support"). Overrides the server default.
